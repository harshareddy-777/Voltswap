# ⚡ QUICK FIX CHECKLIST

## Problem: Can't Create Account or Login

### 🔴 **MUST DO** (5 minutes)

- [ ] **Step 1**: Copy `SUPABASE_AUTH_FIX.sql` to Supabase SQL Editor
- [ ] **Step 2**: Run the SQL (click Run button)
- [ ] **Step 3**: Go to Supabase Settings > Authentication > Policies
- [ ] **Step 4**: UNCHECK "Require email confirmation" (allows signup without email)
- [ ] **Step 5**: In app terminal: `flutter clean && flutter pub get && flutter run`

### ✅ **VERIFY** (2 minutes)

After steps above, run this SQL in Supabase:

```sql
SELECT policyname FROM pg_policies WHERE tablename = 'users' ORDER BY policyname;
```

You should see:
- users_insert_own_profile
- users_select_own_profile
- users_update_own_profile

If you see these 3 policies → **You're fixed!** ✅

### 🧪 **TEST** (3 minutes)

1. Open app
2. Click "Sign Up"
3. Fill form and create account
4. Try **different email** if errors occur
5. Check Debug Console (Ctrl+K) for error messages

## Error Messages & Quick Fixes

| Error | Fix |
|-------|-----|
| "new row violates RLS policy" | Run SUPABASE_AUTH_FIX.sql |
| "Email already exists" | Use different email |
| "Email not confirmed" | Uncheck "Require email confirmation" in Auth > Policies |
| "Account not found" | Make sure signup completed successfully first |
| "Invalid credentials" | Check password is correct at login |
